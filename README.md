# Chat Dot — Gemini / ChatGPT — Arch Linux + Hyprland

Переносна вебверсія: знімок видимого стола 1 → ваш чат Gemini або ChatGPT у Firefox на столі 9 → точки біля номерів відповідей. API-ключ НЕ потрібний. Тут немає API-клієнта, ключів, чужого акаунта або адреси чужого чату. Модель обираєте у власному чаті. Діють ліміти вашого вебакаунта.

## 1. Залежності

Для звичайного Firefox із pacman (не Flatpak/Snap), у графічній сесії Hyprland:

```bash
sudo pacman -Syu --needed python python-pillow firefox grim tesseract tesseract-data-eng quickshell libnotify
```

Quickshell (`qs`) малює точки, Tesseract локально читає номери. Hyprland має вже працювати. Ryoku не обов’язковий.

## 2. Встановлення

Розпакуйте архів, відкрийте термінал у розпакованій папці:

```bash
python3 install.py --check
python3 install.py
```

Без sudo! Програма встановлюється в `~/.local/share/gemini-dot-web`, міст Firefox — у `~/.mozilla/native-messaging-hosts/ua.gemini_dot.json`. Основний конфіг Hyprland автоматично не змінюється. Повторний запуск оновлює лише файли цього пакета. Якщо інша версія Gemini Dot вже зареєстрована, встановлювач зупиниться.

## 3. Клавіші й робота прихованого чату

Встановлювач надрукує повні шляхи. Підключіть **лише один** відповідний фрагмент у вашому конфігу Hyprland:

- Якщо конфіг Lua (`hyprland.lua`, Ryoku `user.lua`): додайте надрукований рядок `dofile("/home/ВАШ_КОРИСТУВАЧ/.local/share/gemini-dot-web/hyprland.lua")`.
- Якщо конфіг Hyprlang (`hyprland.conf`) із сучасними правилами `match:class` (0.53–0.54): додайте `source = /home/ВАШ_КОРИСТУВАЧ/.local/share/gemini-dot-web/hyprland.conf`.
- Для старіших конфігів із `windowrulev2`: підключіть натомість `hyprland-legacy.conf`.

Шлях підставте з виводу встановлювача, не копіюйте ВАШ_КОРИСТУВАЧ буквально. Після змін у звичайному Hyprland виконайте `hyprctl reload`, на Ryoku — `ryoku wm act config.reload`. Не додавайте фрагмент у згенеровані файли Ryoku; використовуйте `~/.config/hypr/user.lua`.

**↑ / ↓ будуть глобальними клавішами**, тому їх звичайна дія в програмах перехоплюватиметься. Якщо вони вже зайняті, усуньте конфлікт або змініть клавіші в одному встановленому фрагменті (наприклад на Ctrl+Alt+G/H). Фонове правило стосується лише Firefox із заголовком, який містить `Google Gemini` або `ChatGPT`; воно не перемикає стіл і не змінює фокус. Якщо заголовок браузера інший, адаптуйте `title` у правилі до фактичного заголовка.

## 4. Підключення власного чату

1. У Firefox увійдіть у власний Gemini або ChatGPT, створіть окремий чат і виберіть модель. Задайте власну інструкцію для відповідей (номери через кому або стислий текст). `PROMPT.txt` — лише необов’язковий приклад; програма його не надсилає. Дочекайтеся відповіді, щоб чат мав постійну адресу.
2. Відкрийте `about:debugging#/runtime/this-firefox` → **Load Temporary Add-on / Завантажити тимчасовий додаток**.
3. Виберіть `~/.local/share/gemini-dot-web/web/manifest.json` (у діалозі файла використовуйте повний шлях зі встановлювача).
4. Поверніться до свого чату. Через значок пазла у Firefox відкрийте **Chat Dot — Gemini / ChatGPT**, натисніть **Використовувати цей чат**. Початково чат не вибраний.
5. Перевірте повідомлення про підключення та адресу саме вашого чату. Перенесіть це вікно Firefox на стіл 9; вкладка вибраного чату має залишатися вибраною в цьому вікні.
6. На столі 1 відкрийте тест; для проби є `~/.local/share/gemini-dot-web/check-test/index.html`.

**↑** надсилає знімок, **↓** скасовує очікування та прибирає точки. Стрілки спрацьовують при відпусканні. Дочекайтеся завершення відповіді перед переходом до іншого питання. Точки тримаються приблизно 8 секунд для однієї відповіді й 12 секунд для кількох.

Після перезапуску Firefox потрібно знову завантажити тимчасове розширення. Міст і конфіг клавіш зберігаються; повторно запускати install.py не потрібно. Це непідписане тимчасове розширення, не встановлюйте його як постійний XPI і не вимикайте перевірку підписів.

## Діагностика

```bash
python3 ~/.local/share/gemini-dot-web/web_bridge.py status
python3 ~/.local/share/gemini-dot-web/web_bridge.py diagnose
```

У діагностиці є остання відповідь вибраного чату (до 500 символів). Знімок має показувати одне питання повністю з варіантами, пронумерованими від 1, в одній або двох колонках. Столи 1 і 9 — саме номери робочих просторів. Скриншоти, надіслані Gemini, залишаються в історії чату навіть після скасування.

Вебінтерфейс Gemini може змінюватися, OCR та сама модель можуть помилятися. На вихідному комп’ютері перевірено один монітор із прихованим столом 9; на комп’ютері одержувача потрібна проба на включеному тренувальному тесті.

## Видалення

Приберіть доданий `source` / `dofile` зі свого конфігу та перезавантажте Hyprland. Видаліть тимчасове розширення через about:debugging. Після цього можна видалити `~/.local/share/gemini-dot-web` і файл `~/.mozilla/native-messaging-hosts/ua.gemini_dot.json`, переконавшись, що він посилається саме на цю встановлену копію.

## Текстові відповіді та відсутня нумерація

Нерозпізнані або неоднозначні номери більше не блокують надсилання скриншота. Відомі номери відповіді показуються точками. Текст чи номери без координат показуються знизу ліворуч у вікні з автоматичною шириною до 190 px протягом 45 секунд (натискання розгортає до 310 × 166), із прокручуванням, кнопками «Копіювати» та ×. ↓ також закриває вікно. Поки відповідь показана, перед новим запитом закрийте її. Перевірка зміни питання залишається: застаріла відповідь не показується.

Після оновлення натисніть Reload розширення в about:debugging і F5 у вкладці Gemini. Власні правила для числових і текстових відповідей задайте на початку чату.

## ChatGPT у Firefox

Розширення Chat Dot підтримує також https://chatgpt.com. Відкрийте існуючу розмову (адреса /c/…, також підтримуються розмови в проєктах /g/…/c/…), а не порожню стартову сторінку. Після Reload розширення та F5 відкрийте його панель і натисніть «Використовувати цей чат». До ChatGPT надсилається лише скриншот, без додаткових інструкцій. Правила відповіді користувач задає сам на початку чату. API-ключ не потрібний. Обрану в чаті модель розширення не змінює.

Для прихованого стола фонове правило має збігатися із заголовком вікна Firefox. Якщо заголовок містить лише назву розмови без ChatGPT, додайте цю назву в правило title. Старі розмови Gemini залишаються доступними через повторний вибір чату.

Панель відповіді має один рядок із шириною за текстом, шрифт 12 px, знизу ліворуч. Натисніть її для повного тексту, прокручування й копіювання. ↓ закриває панель; повторний запит запускається після її закриття.

Перевірка 28.10.2026: ChatGPT у Firefox на прихованому столі 9 прийняв знімок стола 1, завершену числову відповідь повернуто до локальної програми, цикл показу завершився без помилки. Адаптер підтримує поточний інтерфейс ProseMirror / data-talvt-turn-state і попередню структуру повідомлень. Текст запиту, кнопки та службові підписи не включаються у відповідь.

Компактна текстова панель автоматично підлаштовується під фактичну ширину тексту (шрифт 12 px, відступи 4 px з боків і 2 px зверху/знизу). Максимальна компактна ширина — 190 px; довгий текст розгортається натисканням. Одна цифра більше не займає всю ширину панелі.
